3. Привязка и доступность
Номера строк, названия «Объект N» и количество датчиков не являются ключом к ид_объект. Использование записи допускается только при явной привязке пары SHA256 книги и object_key к ID из справочника и наличии непустых оснований соответствия и доступности. available_at задаётся с часовым поясом, значение должно быть не позже as_of. Частичные привязки допустимы; непривязанные и ещё недоступные записи исключаются из результата для моделирования. План не означает выполненный ремонт, отсутствие отметки не означает исправность.

4. Проверка
Проверить чтение обоих форматов, вертикальные объединения без переноса за их границы, скрытые строки, повторные заголовки, одиночные отметки, системы дат 1900/1904, интервалы месяцев, порядок этапов и независимость от имени листа. Проверить запрет числовой автопривязки, неверного SHA256, неоднозначных ключей, отсутствующих оснований, неизвестных ID, дат без часового пояса и будущей доступности. Сверить реальные итоги независимым подсчётом из ZIP/XML. Реальные строки и исходные книги в git не добавлять.
