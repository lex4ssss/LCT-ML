# ML-часть прогноза рисков для Москоллектора

Два прогноза по объектам проходят ориентир организаторов (precision > 0,7 при recall > 0,5) на отложенном периоде январь–июнь 2026 года:

| прогноз | горизонт | precision | recall | доля положительных | правило «тревога в объекте за сутки», precision / recall |
|---|---|---|---|---|---|
| инцидент в объекте | 72 ч | 0,827 | 0,616 | 0,347 | 0,573 / 0,492 |
| «Неисправен» в объекте | 7 сут | 0,869 | 0,625 | 0,239 | 0,343 / 0,428 |

Инцидент: начало записанного эпизода «Не замкнут», «Обнаружен дым», «Обнаружен газ», «Затоплен» и других тревог этого класса. Отказ: начало эпизода «Неисправен». Единица подсчёта: объект за сутки, организаторы оставили её выбор команде (§17 ответов). Это записанные в журнале эпизоды, подтверждённой аварией они не являются.

## Запуск

Нужен Python 3.12. Тесты работают на искусственных данных, реальный датасет им не нужен.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r outputs/ml-service/requirements.txt
ML_PYTHON=.venv/bin/python bash scripts/test.sh
```

Сервис прогноза с обеими моделями, картой рисков по объектам и причинами прогноза описан в [outputs/ml-service/README.md](outputs/ml-service/README.md). Ему нужен подготовленный журнал: как его собрать из архива организаторов, написано в [docs/REPRODUCE.md](docs/REPRODUCE.md).

## Как получены цифры

1. Правило отбора модели и порога записывалось в spec и коммитилось до прогона. Спецификации лежат рядом с кодом: `outputs/ml-baseline-v2/spec_*.txt`.
2. Модели учились на данных до 2025 года, порог и выбор постановки брались по 2025 году, отложенный период 2026 года проверялся один раз на модель.
3. Этот период открывался и для более ранних моделей, это записано в отчётах рядом с каждой цифрой.
4. Рядом с каждой цифрой стоят доля положительных и простое правило, чтобы было видно, сколько добавляет модель.

Полный ход экспериментов, включая непринятые (погода, признаки соседних каналов): [outputs/ml-baseline-v2/README.md](outputs/ml-baseline-v2/README.md).

## Устройство репозитория

Данные:
1. [outputs/ml-archive](outputs/ml-archive): аудит полного архива журнала, 313 млн строк 2019–2026 годов.
2. [outputs/ml-dataset](outputs/ml-dataset) и [outputs/ml-dataset-v2](outputs/ml-dataset-v2): эпизоды тревог, снимки каналов, метки и их проверки.

Модели и сервис:
1. [outputs/ml-baseline-v2](outputs/ml-baseline-v2): эксперименты run-002…run-009, модели объектов, калибровка.
2. [outputs/ml-service](outputs/ml-service): HTTP-сервис прогноза и патчи для backend.

История ранних этапов: [outputs/ml-workplan.md](outputs/ml-workplan.md) (постановка), [outputs/ml-audit](outputs/ml-audit) (аудит), [outputs/ml-stage1](outputs/ml-stage1), [outputs/ml-stage2](outputs/ml-stage2) и [outputs/ml-baseline](outputs/ml-baseline) (загрузчик, эталон эпизодов, первая модель).

Реальные журналы и построчные производные данные в git не входят. Происхождение датасета и контрольные суммы: [docs/sources.json](docs/sources.json), результаты проверок воспроизведения: [docs/VERIFICATION.md](docs/VERIFICATION.md).
